# 00 はじめに

## この本の範囲

この本は、Swift（1年生・後期）の授業で扱う文法だけを載せています。Swift の全部ではありません。授業の単元 1〜9 に対応する 9 章と、付録 5 つでできています。

Java を並行して学んでいる人が読む前提で書いています。各章の最初に「概念と Java との対応」という表があり、Java でどう書いていたかから Swift の書き方に入ります。同じ概念が Kotlin、TypeScript、Go、Rust ではどう現れるかは、付録A にまとめてあります。次の言語に進むときに使ってください。

## 読み方

各章は同じ順番で書いてあります。

| 節 | 何が書いてあるか | いつ読むか |
|------|------|------|
| この章で分かること | 3〜5 行の要約 | 月曜の授業の前 |
| 概念と Java との対応 | 対応表 | 月曜の授業の前 |
| 文法の説明と実行できる例 | 説明と、教材コードと同じコード | 月曜の授業中、金曜の演習中 |
| よくある間違い | コンパイルエラーの読み方と、動くけれど間違っている例 | 演習で詰まったとき |
| 確認テストで問われること | 出力予測、誤り指摘、白紙再実装の対象 | 次の月曜の前 |
| 詳解Swift 第5版の対応節 | もっと詳しく知りたいときの案内 | 必要なとき |

## コードの実行のしかた

この本のコードは、その週の教材コード `weekNN/main.swift` に入っています。Xcode で Command Line Tool のプロジェクトを作り、`main.swift` に貼って ⌘R で実行できます。手順は教材コードリポジトリの README にあります。

コードは Swift 6 の言語モードで動作を確認しています。Xcode 26.6 を基準にしています。Xcode 27 でも、この本の範囲では同じように動くはずですが、授業では 26.6 を使います。

## この本に載っていないこと

- SwiftUI の書き方（前期の「iOSプログラミングI」と来年度の「iOSプログラミングII」で扱います）
- 並行処理（`async`/`await`、`actor`）の詳しい説明（第9章で「読める」ところまでにします）
- マクロの作り方（第9章で `#Preview` と `@Observable` が何かを読めるところまでにします）
- Swift の全部の文法。網羅的な資料は [swiftlangjp.com](https://www.swiftlangjp.com)（The Swift Programming Language の日本語訳、Swift 6.2 対応）と『詳解 Swift 第5版』（2019、Swift 5 対応）を使ってください。詳解Swift は Swift 5 の本ですが、この本で扱う範囲の文法はほとんど変わっていません。変わった点は付録B に書きます

## 持ち帰り方

学期の最後に、この本の全章を一つの PDF にして配ります。自分の学習ノート（NOTE.md）と、期末試験用に作る A4 一枚のシートと合わせて、一冊にまとめる手順も配ります。この本は先生が書いたものですが、書き込みはあなたのものです。就職してからも手元に置いてください。
