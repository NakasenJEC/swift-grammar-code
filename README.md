# Swift 文法基礎 教材コードとリファレンス

Swift（1年生・後期、2026年度）で使う教材コード（週ごとの `main.swift`）と、リファレンス「Swift 文法リファレンス 2026（Java 経験者のための）」です。

## 最初に1回だけ：Xcode のプロジェクトを作る（9/28 の授業で一緒にやります）

1. Xcode で **File > New > Project... > macOS > Command Line Tool** を選び、名前を `SwiftGrammar` にして作る
2. 左の一覧で一番上の `SwiftGrammar`（青いアイコン）をクリックし、**TARGETS** の `SwiftGrammar` を選ぶ
3. **Build Settings** タブを開き、**All** を選んで、右上の検索欄に `Swift Language Version` と入れる
4. 「Swift Compiler - Language」の中の「Swift Language Version」の値を **Swift 6** にする
5. このプロジェクトを学期の最後まで使います。消さないでください。作り直したときは 2〜4 をもう一度やります

## 毎週の取得方法（金曜の演習の前に）

1. `weekNN/main.swift` を開く（NN はその週の番号）
2. 右上の「**Raw**」ボタンを押す
3. 表示された文字をすべて選択（⌘A）してコピー（⌘C）
4. Xcode で `SwiftGrammar` の `main.swift` を開き、中身をすべて消して貼り付ける（⌘V）。前の週のコードは消えてかまいません。学習ノートに上げてあるものが正本です
5. ⌘R で実行する。下のコンソールに `OK` と `NG` の行が出ます。最初の行が `NG  Swift 6 の言語モード` なら、上の「最初に1回だけ」の 2〜4 をやり直してください

ZIP でのダウンロードは使いません。教材コードは、その単元を始める月曜の前の木曜までに公開します。その週のファイルを Raw からコピーしてください。

## OK と NG の見方

各ファイルには `check("名前", 条件)` という行があります。最初の1行は Swift 6 の言語モードの確認で、残りは「演習」と書かれている部分の最後に並んでいます。実行すると 1 行ずつ `OK` か `NG` が出ます。

- 最初の行が `NG  Swift 6 の言語モード` のときは、演習の前にプロジェクトの設定を直します（上の「最初に1回だけ」の 2〜4）
- 最初に実行したときは、「演習」と書かれている部分の `NG` がいくつか出ます。それが今週の課題です
- 演習の関数を完成させて、`NG` をすべて `OK` にしてください
- すべて `OK` になった `main.swift` を、自分の学習ノートの `weekNN/main.swift` に **Upload files** で上書きしてコミットします
- `NG` を `OK` にするために、`check` の行を書き換えたり消したりしてはいけません

## 注意

- 教材コードは Swift 6 の言語モードで書いてあります。Xcode 26.6 で動作を確認しています
- コードのコメントには「何をしているか」だけ書いてあります。「なぜそう書くか」は、授業と生成AIへの質問で自分で見つけて、学習ノートに書いてください
- 教材コードにも間違いが残っていることがあります。おかしいと思ったら、それは良い発見です。学習ノートに書いて、授業で教えてください
